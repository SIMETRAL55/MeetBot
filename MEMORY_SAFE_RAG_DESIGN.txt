Memory-Safe RAG Indexing — System Design
=========================================

Overview
--------
The indexing pipeline processes transcript segments into a searchable vector
index.  The memory-safe design ensures large jobs (60+ MB audio → 1000+ segments)
never cause OS OOM kills by:

  1. Batching embeddings into EMBED_BATCH_SIZE groups (default 16).
  2. Streaming intermediate doc lists to JSONL on disk.
  3. Freeing memory (gc.collect + CUDA flush) between every batch.
  4. Monitoring system RAM via psutil with adaptive batch halving.
  5. Cooperative cancellation between batches.

Three Embedding Levels (Single Collection)
------------------------------------------

  ┌─────────────────────────────────────────────────────────┐
  │              Chroma Collection                          │
  │                                                         │
  │  level="document"  │ 1 vector:  full concatenated text  │
  │                    │ → broad "what was discussed" queries│
  │  ─────────────────────────────────────────────────────  │
  │  level="segment"   │ 1 vector per segment               │
  │                    │ → speaker-specific, timestamped     │
  │  ─────────────────────────────────────────────────────  │
  │  level="chunk"     │ Overlapping chunks (Chunker)        │
  │                    │ → factual retrieval + MMR reranking │
  └─────────────────────────────────────────────────────────┘


Configuration (Environment Variables)
--------------------------------------

  EMBED_BATCH_SIZE             = 16     # docs per embedding batch
  INDEX_BATCH_PERSIST_CHECKPOINT = 100  # log every N batches
  MEMORY_WATCH_ENABLED         = true   # enable psutil monitoring
  MEMORY_WATCH_THRESHOLD_PCT   = 0.85   # system RAM pressure threshold
  RAG_MEMORY_SAFE_MODE         = true   # use batched path (vs legacy)
  TEMP_DIR                     = ./temp # JSONL intermediate storage


Memory Hygiene Strategy
-----------------------

  Between pipeline stages (transcribe → diarize → align → index):
    • del large variables (transcriber_svc, diarizer_svc, etc.)
    • gc.collect() + torch.cuda.empty_cache()
    • log RSS via psutil

  Between embedding batches:
    • del embeddings, texts, ids, metadatas
    • gc.collect() + CUDA flush
    • If memory_pressure > threshold: halve batch and retry

  Intermediate storage:
    • Multilevel docs written to JSONL on disk (temp/<job_id>/)
    • Read back in streaming fashion
    • Deleted in finally block


Cooperative Cancellation
------------------------

  cancel_registry.check_and_raise(job_id)
        │
        ▼
  CancelChecker callable passed through:
    pipeline_worker._cancel_check()
        → build_multilevel_index_atomic(cancel_checker=...)
            → build_index_atomic(cancel_checker=...)
                → _build_chroma_index_batched(cancel_checker=...)
                    → checked between every batch


Atomic Swap Protocol
--------------------

  1. Build index in   <collection>.tmp/
  2. Rename existing  <collection>/    →  <collection>.old/
  3. Rename           <collection>.tmp/  →  <collection>/
  4. Delete           <collection>.old/
  5. Invalidate chromadb process cache

  On failure at step 3: restore <collection>.old/ → <collection>/
